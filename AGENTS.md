# NetSuite MCP Server — AI Developer Guide

This repository contains the source code for the **NetSuite MCP Server** (`@suiteinsider/netsuite-mcp`). It exposes NetSuite functionalities to AI agents over the Model Context Protocol (MCP).

**Tech Stack:** TypeScript (strict) · Node.js ≥ 18 (ESM) · OAuth 2.0 PKCE · Dual-layer cache (L1 in-memory + L2 file system)

## 🔒 Critical Rules (Always Active)

### Write Operations Control

> [!IMPORTANT]
> Write operations (`ns_createRecord`, `ns_updateRecord`) are strictly disabled in **Production environments**. They are **fully enabled in Sandbox/Test environments** (account IDs containing `_SB` or starting with `TSTDRV`). Environment detection is centralized in `src/utils/environment.ts` via `isSandboxAccount()`.

### SuiteQL Protocol & Self-Healing Rules

> [!IMPORTANT]
> All SuiteQL queries generated by AI agents MUST strictly comply with:
> 1. **Reconnaissance First**: Call `ns_getSuiteQLMetadata` before executing custom SuiteQL queries to verify case-sensitive table and field names.
> 2. **Syntax & Pagination**: No `SELECT *`, use `FETCH FIRST N ROWS ONLY` or `ROWNUM <= N` (NEVER `LIMIT`/`OFFSET`), use `TO_DATE('YYYY-MM-DD', 'YYYY-MM-DD')` for dates, and `BUILTIN.DF(field)` for foreign key text labels. Primary key is `id`.
> 3. **Automatic Self-Healing**: On query error or empty results, automatically parse errors, inspect metadata via `ns_getSuiteQLMetadata`, fix the query, and retry (up to 3 retries) before declaring failure.
